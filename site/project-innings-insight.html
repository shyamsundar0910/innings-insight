Innings Insight is a cricket analytics application built to translate everyday cricket questions into structured analysis and visual answers.

View GitHubBack to projects
The idea

Analytics without writing a query first.

Most cricket datasets are rich but difficult to explore quickly. The goal of this project is to make common analytical questions accessible through a natural-language interface, while keeping the calculation logic transparent and reproducible.

A user can ask about venue scoring, player performance, economy, wickets, phase scoring, pace versus spin, or comparisons between players. The application routes the question to the appropriate analytical function and returns the answer with supporting context and charts.

What the first version answers

  • Average first-innings and second-innings scores by venue.
  • Highest run scorers, strike rates, wickets and economy rates.
  • Powerplay team scoring and death-over batting.
  • Pace versus spin performance.
  • Player-to-player comparisons.

How it is built

The current version uses Python for data processing and analytical functions, a routing layer for mapping user questions to the correct calculation, and Streamlit with Plotly for the interactive interface. The backend and data logic live in the same public GitHub repository linked above.

Why it matters

The project is less about building a chatbot and more about building a reliable cricket-analysis layer. The language interface is only useful when the underlying metric definitions, filters and aggregations are correct.
